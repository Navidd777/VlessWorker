# Subscription files

GitHub Actions fetches fresh subscription content from the Cloudflare Worker every 6 hours and writes it here.

Files (after first run):
- `sub-xray.txt` — Xray/v2ray clients
- `sub-sb.txt` — S-UI / sing-box clients
- `sub-all.b64` — base64 combined

Subscribe URL on the phone (v2rayNG etc.):
https://navidd777.github.io/VlessWorker/sub-xray.txt
